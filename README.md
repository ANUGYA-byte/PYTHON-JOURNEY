## ▶️ How to Run

1. Install [Python 3](https://www.python.org/downloads/).
2. Clone the repo:
```bash
   git clone https://github.com/ANUGYA-byte/PYTHON-JOURNEY.git
   cd PYTHON-JOURNEY
```
3. Run any program:
```bash
   python 03_loops/<filename>.py
```
